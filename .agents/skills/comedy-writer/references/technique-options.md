# Six revision prompts

Use the writer's requested edit distance. Pick a prompt that addresses an actual
problem; do not run every draft through all six. Lead with the revised material.
These are this project's optional editing prompts, informed by the
[practitioner references](sources.md), not a measured quality rubric.

| Draft problem | Try | Check before returning |
|---|---|---|
| The premise is vague | Name a concrete expectation and what collides with it. | Did the revision retain the writer's observation and attitude? |
| The turn feels predictable | Find a plausible second reading of an established word or situation. | Is enough context present for that reading without an explanation after it? |
| The speaker feels detached | Explore what the speaker wants, misunderstands, or implicates themselves in. | Did you invent a personal event or change their position? Self-deprecation is optional. |
| The next beat repeats the last | Keep the premise's logic but change one pressure, consequence, scale, or point of view. | Does it develop the bit, or merely repeat it more loudly? |
| The join between bits is confusing | Write the missing connection in plain language, then compress it. | Can a first-time listener follow it? A smooth transition need not be a joke. |
| The callback feels forced | Identify the established seed and what its return does here. | Recognition or continuity can be enough. Do not manufacture a new life incident to justify it. |

For a requested explanation, use the [technique catalogue](techniques.md). For a
light punch-up, revise the affected passage rather than adding a craft lesson.
